------------------------------------------------------------
1. WHAT THIS IS
------------------------------------------------------------
A single self-contained index.html — a responsive luxury landing page PLUS a
working "memory book" web app (guided prompts, answers, photos, printable
keepsake), all in one file.
- No build step, no frameworks, no dependencies. Inline CSS (<style>), inline
  JS (<script>), inline SVG logo + icons, data saved via localStorage.
- Deploy = drop index.html (+ optional images) into the repo root.
- Hosted on GitHub Pages at anchorremembers.com.
- Repo: AcKccreate/anchor-remembers (working branch: claude/session-L32eh).

5. HOW IMAGES PLUG INTO THE CODE   (full code — do not strip)
------------------------------------------------------------
All edits are in index.html. Put image files in the SAME folder, reference them
relatively (e.g. src="hero-book.png"), or inline as base64 data URIs.

--- A. Replace the hero CSS book with a photo ---
FIND this block:

    <div class="hero-art">
      <div class="book-scene"> ... </div>
    </div>

REPLACE the inner .book-scene so it becomes:

    <div class="hero-art">
      <img class="hero-photo" src="hero-book.png" alt="AnchorRemembers leather memory book">
    </div>

ADD to the <style>:

    .hero-photo{width:100%;max-width:430px;height:auto;display:block;margin:0 auto;
      filter:drop-shadow(0 24px 48px rgba(13,24,42,.35))}

--- B. Section lifestyle background ---
WRAP any section:

    <section class="photo-band" style="background-image:url('lifestyle.jpg')"> ... </section>

CSS:

    .photo-band{background-size:cover;background-position:center;position:relative}
    .photo-band::before{content:'';position:absolute;inset:0;background:rgba(13,24,42,.45)}

--- C. Botanical sprig accent (parent section must be position:relative) ---
HTML:

    <img class="sprig tl" src="sprig.png" alt="">
    <img class="sprig br" src="sprig.png" alt="">

CSS:

    .sprig{position:absolute;width:120px;opacity:.85;pointer-events:none}
    .sprig.tl{top:10px;left:10px}
    .sprig.br{bottom:10px;right:10px;transform:scaleX(-1)}

--- D. Gallery grid ---
HTML:

    <div class="gallery">
      <img src="j1.png" alt=""><img src="j2.png" alt=""><img src="j3.png" alt="">
    </div>

CSS:

    .gallery{display:grid;grid-template-columns:repeat(3,1fr);gap:12px}
    .gallery img{width:100%;border-radius:12px;box-shadow:0 6px 18px rgba(13,24,42,.1)}

6. ARCHITECTURE NOTES (for any AI editing this file)
------------------------------------------------------------
- USE the :root CSS variables (tokens in §2) — never hardcode colors.
- SVG SPRITE sits right after <body>: holds #arEmblem (logo, embedded PNG) and
  #ic-* line icons. Reference an icon with:
      <svg class="ic"><use href="#ic-book"/></svg>
  Icon size classes: .ic (box-filled), .ti (tab), .bi (inline button),
  .ci (tiny inline), .li (lock).
- RESPONSIVE: mobile-first; desktop overrides inside @media(min-width:880px).
  Landing is one column on phones, multi-column on desktop (match desktop to
  the wide mockup).
- JAVASCRIPT: vanilla, no libraries. Saves to localStorage keys
  aw_anchor_remembers, aw_remembers_pro, aw_anchor_photos.
  DO NOT rename element IDs or onclick handler names — wiring depends on them.
- KEEP IT ONE FILE. Deploy = commit index.html (+ images) to repo root.
